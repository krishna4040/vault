# Basic Terminology

| Term                     | Meaning                                                                                                         |
| ------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Money                    | an asset that functions as a generally accepted medium for transferring economic value.                         |
| Unit of account          | numerical scale in which prices and obligations are expressed, eg inr, dollar                                   |
| Medium of exchange       | anything that can transfer purchasing power, money                                                              |
| Store of value           | Money can also transfer purchasing power                                                                        |
| Inflation                | $\pi_{t}=\frac{P_{t}-P_{t-1}}{P_{t-1}}$                                                                         |
| real growth              | growth adjusted to inflation<br>$G_{real}=\frac{G_{nomial}}{1+\pi}$                                             |
| Interest                 | Compensation associated with lending or borrowing money over time                                               |
| Credit                   | ability to obtain resources now in exchange for a contactual obligation to repay later, which includes interest |
| Debt                     | borrower’s contractural obligation arising from borrowing                                                       |
| Asset                    | resource or claim that provide economic value to its holder                                                     |
| Liability                | An obligation that requires the holder to transfer economic resources in the future.                            |
| Balance Sheet            | Assets = Liabilities + Equity                                                                                   |
| Credit Risk              | risk that contractual repayment is not received as expected                                                     |
| Leverage                 | $Leverage=\frac{Assets}{Equity}$                                                                                |
| Financial Intermediation | institution that stands between lender and borrower, banks                                                      |
|                          |                                                                                                                 |

# Financial Intermediation

It is an institution that stands between lender and borrower. `Banks`
Its functions are

- pooling funds
- evaluating borrowers
- processing payments
- monitoring loans
- managing liquidity
- transforming maturities
- diversifying exposures
