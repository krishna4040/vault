# Functions

Let A and B be two non-empty sets, Then a function f from set A to set B is a rule/correspondence which associates elements of set A to elements of set B sucht that to each element of A, there exist one and only one element of B. if f is a function from A to B, we denote as $f:A\to B$
**Domain**
A is called domain of f
**CoDomain**
B is called codomain of f
**Range**
$R_{f}=\{ y\epsilon B|y=f(x),x\epsilon A \}$

> [!tip]
> Drawing line parallel to y axis tells weather a relation is function or not

## Types of Function

**Constant Function**
f(x) = c

**Identity Function**
f(x)=x

**Odd Function**
f(-x) = -f(x)
_Symmetrical about origin_

**Even Functionis**
f(x) = f(-x)
_Symmetrical about y axis_

**Modulus function**
f(x) = |x| it is an even function

**GIF**
f(x) = \[x], floor value

**Exponential function**
f(x)=a^x

**Log Function**
f(x)=log(x)

## Special Types of Functions

### One One Function (Injection)

$\exists x,y\epsilon A \text{ s.t. } x\neq y \implies f(x)\neq f(y)$

### Many One Function

$\exists x,y\epsilon A \text{ s.t. } x\neq y \implies f(x)=f(y)$

### Onto Function (Surjection)

$R_{f}=C_{f}$

### One One Onto (Bijection)

A function which is One one and Onto is called Bijection or Bijective map and its _Inverse_ exists

#### Inverse of a Bijection

$f:A\to B \text{ is a bijection, and  } y = f(x)$
then,
$f^{-1}:B\to A \text{ then we can express } x = g(y) \text{ and } g = f^{-1}$
