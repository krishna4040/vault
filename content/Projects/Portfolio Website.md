# Overview

- \[Name::Portfolio Website]
- \[Description::Design and launch a personal portfolio website to showcase skills, projects, and writing as part of personal branding]

# Goals / Outcomes

**Purpose (Primary Goal)**

> Establish a strong online presence with a dedicated portfolio site that acts as a central hub for personal brand — showcasing projects, blog, resume, and contact.

**Sub Goal**

- [ ] Design & layout (wireframe, color scheme, typography)
- [ ] Build core pages (Home, About, Projects, Blog, Contact)
- [ ] Write bio and project descriptions
- [ ] Connect custom domain
- [ ] SEO setup (meta tags, sitemap, robots.txt)
- [ ] Deploy to production
- [ ] Link from all social profiles (LinkedIn, GitHub, Twitter)

**Success Metrics (Checks)**

| Metric                  | Type    | Current | Target          | Cadence |
| ----------------------- | ------- | ------- | --------------- | ------- |
| Pages Built             | Process | 0       | 5               | Weekly  |
| Site Live               | Output  | No      | Yes             | -       |
| Google Indexed          | Outcome | No      | Yes             | Monthly |
| Monthly Visitors        | Outcome | 0       | 500/month       | Monthly |
| Avg Session Duration    | Outcome | -       | >1 min          | Monthly |
| Inbound Leads via Site  | Outcome | 0       | 2–5/month       | Monthly |

**Definition of Done**

> Site is live on custom domain, all core pages complete, indexed by Google, and linked from all social profiles.
